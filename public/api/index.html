YumFam public API

Read-only lookup of YumFam's public content: deal pages, guides, sitemap, llms.txt and machine-readable catalogs. No login, no API key, no booking and no write operations. Booking links on deal pages go to the OTA platform, not through this API.

  • OpenAPI document — every read-only route, in OpenAPI 3.0 format.
  • API catalog (RFC 9727 linkset) — the same document, also at /.well-known/api-catalog.json.
  • llms.txt — site guide for agents.
  • sitemap.xml — every public page.
  • ai-catalog.json — agent resource discovery catalog.

Every content page also has a Markdown twin: the same URL returns Markdown when requested with Accept: text/markdown, or open {page-url}index.md directly.
